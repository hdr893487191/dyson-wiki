# 戴森球计划 · 材料合成路径

查询《戴森球计划》材料配方、完整合成树，以及按目标产量估算的满速产线。

## 在线使用

https://hdr893487191.github.io/dyson-wiki/

## 本地打开

用浏览器打开 `dyson-matrix.html` 即可，数据已写在页面里，不依赖服务器。

## 功能

- 全部材料的合成配方，多种路径可切换
- **全部展开**：一次画出完整合成树；带「可切换」的节点可更换上游配方
- 满速产线：机器数、原料需求、物流粗算
- 有机晶体：矿物采集 / 化工合成（塑料 + 精炼油 + 水）；种植仅手动备注
- 氢、重氢：默认按气态巨星轨道采集，也可切合成配方
- 硅石在产线中按直接获取计算
